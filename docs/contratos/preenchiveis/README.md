# Biblioteca preenchível RODAVOLT

22 modelos e formulários, versão 2026-11-04.1. Minutas para revisão profissional.

Abra **Meu advogado → Preparar um documento** para preencher os campos e gerar TXT ou HTML imprimível em PDF. A opção **Pacote de entrada** reúne 8 modelos. A base reutilizável não inclui motorista, ocorrência, terceiro ou assinatura. Os campos são temporários; salve o arquivo em local privado antes de fechar a aba.

Seguro e crédito usam formulários de solicitação/conferência: a apólice e o contrato de financiamento devem vir dos fornecedores. Recibos só comprovam fatos efetivamente confirmados. Documentos gerados não alteram contratos operacionais nem registram aprovação/assinatura.
